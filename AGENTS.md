# UI icon guidance

Use Phosphor Icons for interface icons throughout the project. Prefer the existing Phosphor package and match icon weight and sizing to the surrounding UI.

# Token usage

At the end of every response, list token consumption and cost as: `Token consumption: input [count], output [count], total [count]; cost: $[USD] / ₱[PHP]`. If exact counts or prices are unavailable, provide reasonable estimates and label the affected values `estimated`.

# Ponytail skill

Use the ponytail skill on every task and every response, at full intensity by default. Keep it active unless explicitly told to stop or switch intensity.
